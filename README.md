# OVERBURST

OVERBURST는 대검과 원소의 힘으로 몬스터 무리를 돌파하는 3D 쿼터뷰 핵앤슬래시 액션 RPG입니다. 현재 개발 중입니다.

## 대검과 패링

약공을 맞혀 원소 에너지를 쌓고, 강공으로 모은 에너지를 한 번에 방출합니다. 적을 한곳에 모아 내려찍거나, 회피로 포위망을 벗어나 다시 공격할 자리를 잡습니다.

적의 공격에 맞춰 강공을 쓰면 패링으로 받아칠 수 있습니다. 보스전에서는 공격 예고를 읽고 패링과 회피로 빈틈을 만들어 반격합니다.

## 원소와 장비

대검에 장착한 보석으로 불·얼음·번개·빛·어둠의 힘을 사용합니다. 불은 연쇄 폭발을 일으키고, 얼음은 적을 얼린 뒤 강공으로 깨뜨립니다. 어떤 보석을 쓰느냐에 따라 강공의 효과와 싸우는 방식이 달라집니다.

몬스터를 사냥하며 무기와 장비, 원소보석을 모읍니다. 얻은 아이템의 옵션을 살펴보고 장비를 바꾸며 다음 던전에 도전합니다.

## 지도 던전

마을에서 장비를 정비하고 의뢰를 받은 뒤, 지도 한 장을 사용해 사막이나 동굴로 떠납니다. 동굴에서는 매번 다른 형태로 이어진 플랫폼과 다리를 따라 몬스터를 토벌합니다. 사막에서는 무리를 뚫고 보스가 기다리는 전장으로 향합니다.

목표를 달성하면 다음 지도와 귀환 포탈을 얻습니다. 바로 돌아가거나 남은 적을 더 사냥할 수 있지만, 귀환 전에 죽으면 이번 던전에서 얻은 전리품을 잃습니다.
